# WordCraft 自定义 API 中英翻译

2026-10-28，`0.11.0-api.20261028.2`：同步 GridCraft 的本机 PCB 专业词库能力。三个翻译按钮都只发送命中词条并优先参考术语，不连接原网站。

## 本机 PCB 专业词库

在 API 设置中查看数量、导入 JSON、刷新；`ui.api.glossary={}` 返回元信息，显式 `{"path":"/绝对路径/词库.json"}` 导入而不弹窗。
支持 PCBtool 的 en/zh/category/aliases 数组或含 items 的对象，最多 5000 条 / 4 MB，校验后原子替换；错误时原文件不变。
词库独立保存为 WordCraft 用户配置目录的 `pcb-glossary.json`；不复制 API 密钥，不进入 DOCX、源码或安装包。
最长词组优先，英文词有边界；多义候选按上下文判断，已知错误 `Copper clad / 铜箔` 留档但不参与匹配。
新增压合/press-fit 与无来源附件陈述的本机检查；保持无自动计费重试策略，拒绝不安全结果。
已完整双语不自动改写，关键工程语义仍需人工校核；词库不是全面正确性保证。
此次本机自动导入 733 条本地备份术语（1 条隔离、40 组多义），其他电脑可导入自己的 JSON；个人词库不公开分发。

更新：2026-10-27；版本：0.11.0-wordcraft.20261027.2。定制功能，不代表上游整体就绪度提高。

“开始”功能区点击“API 设置”，选择服务商并填写地址、模型 ID、API Key。六个预设为 GPT / OpenAI、MiniMax、DeepSeek、Kimi、小米 MiMo、自定义；地址和模型均可编辑，以账户控制台为准。MiniMax 国内账号可改用 https://api.minimaxi.com/v1。

支持 OpenAI 兼容 Chat Completions / Responses、Bearer / api-key、Base URL / 完整端点、10–600秒超时、附加 JSON。附加参数不能覆盖消息、模型、工具和存储策略。不保证厂商全部专有接口兼容。

密钥默认仅进程内，可选系统钥匙串 / Windows 凭据管理器（独立 WordCraft 命名空间）。普通 ai-api.json 不含密钥，位于 WordCraft 系统用户设置目录。WORDCRAFT_NO_PREFS 测试模式不读写配置。不自动复制 GridCraft 密钥。

三个翻译按钮：选区转英文、全文转英文、选区转中文。打开文件/框选不会发送。点击翻译才冻结文档、精确选区和当前 API 配置，后台处理候选文字。保留反向选区、UTF-8 字符边界、表格及特殊内容保护，图片不上传。翻译在原文后补充，生成独立 DOCX 副本，不覆盖原窗口后续编辑。

本机去重，按最多16种文本/约6000字符分批；单段及总量仍受引擎限制。拟跳过项复核一次，可能增加计费。模型/网络错误不自动重试。数字、公差、型号不符或 JSON ID 缺失/重复则拒绝生成。语义判断仍需人工核对。

连接测试仅发送“请只回复：连接成功”，不发送文档，可能产生少量费用。默认 HTTPS，不跟随重定向；本机可 HTTP，远程 HTTP 须显式允许。取消无法删除服务商已收到的数据。
